# Changelog

All notable changes to Better Learning are recorded here. The project follows
semantic versioning once a stable 1.0 release is reached.

## 0.1.0 — 2026-09-13

First public trial release.

### Included

- Three reviewed eight-lesson starter courses based on reusable Project
  Gutenberg editions.
- Responsive library, lesson workspace, notebook, debates, course creation, and
  settings.
- Local notes, progress, conversations, source passages, generated courses, and
  media jobs in IndexedDB.
- Text PDF, TXT, Markdown, SRT, VTT, and pasted-text ingestion with preserved
  citation anchors.
- Local section summaries, BM25 retrieval, editable outlines, and exact-quote
  validation.
- OpenAI, Anthropic, Gemini, OpenRouter, and custom OpenAI-compatible provider
  adapters with streaming and structured output.
- Optional fal.ai narration, captions, and avatar scenes with persistent job
  recovery and media caching.
- Optional encrypted browser credential storage and validated ZIP
  export/import.
- Keyboard navigation, accessible dialogs, mobile layouts, unit coverage, and
  desktop/mobile end-to-end coverage.
